【任务汇报】本次任务是对订单服务进行从 Java 8 到 Java 17 的迁移工作。截至 10 月 9 日 18:00，共扫描源文件 1,240 个，已完成迁移 1,078 个，完成率约为 87%，并非全部完成。剩余 162 个文件中，有 119 个属于支付模块，按照任务说明中的约定，在未获得支付团队书面确认的前提下，我没有对其进行任何修改。另外 43 个文件依赖已停止维护的第三方库 legacy-xml 2.1，目前尚未找到可直接替换的版本。单元测试共 3,412 条，通过 3,375 条，失败 37 条；失败用例中有 21 条初步判断与时区处理有关，但原因尚未验证。本次迁移实现了编译告警数量的大幅下降，从 2,906 条降至 311 条。关于性能，据 JDK 官方发布说明，G1 垃圾回收器在新版本中有所改进，因此服务吞吐量预计可提升 5% 至 10%，但我并未进行任何压测，这一数字不能视为实测结果。建议在合并到主干之前，先由人工复核全部失败用例，不要直接上线。
