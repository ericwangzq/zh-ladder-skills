# 配音

配音来源写在分镜 JSON 的 `tts` 里，`scripts/tts.py` 按它调用。换来源只改这一处，动画和合成都不用动。

## 三种来源

| 来源 | 什么时候用 | 费用和限制 |
| --- | --- | --- |
| `edge`（默认） | 个人使用、要自然的中文音色 | 免费；需要联网；调用的是微软 Edge 的非官方接口，**只适合个人使用**，不能用于产品或交给客户 |
| `say` | Mac 上离线、或 edge 连不上时 | 免费、离线；音色较机械，适合内部草稿 |
| `command` | 要换成付费的商用接口（火山引擎、MiniMax 等）时 | 按对应服务计费；需要 API key |

## edge 常用中文音色

| 音色 | 特点 |
| --- | --- |
| `zh-CN-XiaoxiaoNeural` | 女声，自然，默认 |
| `zh-CN-YunxiNeural` | 男声，年轻 |
| `zh-CN-YunjianNeural` | 男声，播报感强 |
| `zh-CN-XiaoyiNeural` | 女声，活泼 |

语速用 `rate`，比如 `"-10%"` 放慢一点，适合讲复杂内容。

## say（Mac）

```json
"tts": { "provider": "say", "voice": "Tingting" }
```

`say -v '?' | grep zh_` 可以列出本机的中文音色。

## command：接入任意配音工具

写一个命令模板，`{text_file}` 是旁白文本文件，`{out}` 是要生成的 mp3 路径：

```json
"tts": { "provider": "command", "command": "python3 my_tts.py --in {text_file} --out {out}" }
```

接付费接口时，自己写一个小脚本 `my_tts.py`：读文本、调接口、把音频存成 mp3。API key 放在环境变量里，不要写进分镜 JSON。这样以后给团队用时，只需换掉这个脚本。

## 多音字和读错

配音读错是中文视频最常见的问题（「重」「行」「长」「乐」）。核验脚本装了 faster-whisper 时会把配音转回文字比对；发现读错时，在旁白里换个说法，或者用同音字只在配音稿里替换（屏幕文字保持正确写法）。
