# 核验

视频是最难核对的形式：画面、声音、文字同时出现，错误很容易被动画盖过去。核验分两步：脚本查机械问题，人看内容。

## 脚本查什么

`scripts/verify_video.py 成片.mp4 --storyboard 分镜.json --out check/`

| 检查 | 不通过时 |
| --- | --- |
| 有视频、音频、字幕三条轨 | 合成时漏了；字幕烧进画面的话没有字幕轨是正常的 |
| 音视频时长差不超过 0.5 秒 | 动画没按 `timings.json` 对齐，回去调 `begin`/`finish` |
| 没有超过 1.5 秒的静音（片尾除外） | 某个镜头动画太长或配音缺失 |
| 配音转写与旁白相似度 ≥ 0.85（需 faster-whisper） | 读错、漏读、多音字 |

`tts.py` 在生成配音前还会检查分镜：屏幕上的数字旁白里有没有、旁白里的「约」「预计」屏幕上丢没丢、屏幕文字是否超过 14 个汉字。

## 人看什么

打开 `check/总览.png`（每两秒一帧），逐格看：

1. 第一格是标题卡，最后几格是总结卡。
2. 中文没有方块，文字没有出画、没有被别的元素压住。
3. 每格的画面和那几秒的旁白讲的是同一件事（对照 `subtitles.srt` 的时间）。
4. 数字和原文一致；推算、未确认的内容在画面上有标注。
5. 一个镜头里只有一处强调色。

有问题的格，去 `check/frames/` 看单帧大图。

## 交付时怎么说

- 全部通过：说明时长、核验方式（脚本 + 看了总览图）。
- 部分没做：明说哪项没做，比如「未装 faster-whisper，没有做配音转写比对」。
- 不要在没看总览图的情况下说「检查过了」。
