# 严格模式

用于：操作手册、部署和排障步骤、接口和参数说明，或用户明确要求「严格」「简明技术中文」「一词一义」时。也适合交给能力较弱的模型执行：规则越具体，它越不容易跑偏。

不用于：说明性的长段落、汇报、摘要、给领导的解释。句长上限会把这类文字切碎，主语反复出现，实测读起来比不用更慢。

## 规则来源

本模式使用「简明技术中文（STC）」0.2：

- 规范：`stc/规范.md`
- 词表：`stc/词表.md`
- 检查脚本：`../scripts/stc_check.py`

> 简明技术中文（STC）0.2，作者 mzopedia，<https://github.com/mzopedia/simplified-technical-chinese>，规范和词表以 CC BY 4.0 许可（见 `stc/LICENSE-CC-BY-4.0`），检查脚本以 MIT 许可。本项目未修改规范和词表的内容；只改了检查脚本里词表文件的路径。

## 做法

1. 先按 SKILL.md 的第 1、2 步认清任务、列保真清单。严格模式不改变保真要求。
2. 读 `stc/规范.md`，执行全部【必须】规则；用户说「全部规则」时也执行【建议】规则。
3. 写完运行：

   ```bash
   python3 -I ${CLAUDE_SKILL_DIR}/scripts/stc_check.py 新稿文件
   ```

4. 按脚本的提示修改，但**保真清单优先**：改掉一条提示会丢信息或改意思时，不改。

## 已知误报

脚本按词面匹配，不懂领域含义。下面这些在政务、法务、金融文本里是正常用词，提示可以忽略：

- 「注销」：企业注销、账户注销，不是「退出登录」。
