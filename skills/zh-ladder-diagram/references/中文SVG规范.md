# 中文 SVG 规范

所有数字都在 Chromium 里实测过（Linux 上的 Noto Sans CJK SC）。Mac 上会用苹方（PingFang SC），汉字宽度相同，字母和数字略有出入，所以公式留了余量。

## 画布

- `viewBox="0 0 960 H"`，H 按内容定，四周留 32px 白边。
- 第一个元素铺一个白色背景：`<rect width="100%" height="100%" fill="#ffffff"/>`。不铺的话，PNG 是透明底，贴到深色背景上看不见字。
- 所有坐标取 8 的倍数，框与框之间至少 24px。

## 字体和字号

在根 `<svg>` 上统一写字体：

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 960 520"
     font-family="'PingFang SC','Noto Sans CJK SC','Microsoft YaHei',sans-serif">
```

只写一个字体名时，缺这个字体的机器会退回到无法预料的字体，字母甚至会变成衬线体。

| 用途 | 字号 | 字重 | 颜色 |
| --- | --- | --- | --- |
| 标题（一句结论） | 18 | 600 | `#1f2329` |
| 节点名 | 14 | 600 | `#1f2329` |
| 节点说明 | 13 | 400 | `#1f2329` |
| 连线标签、注释 | 12 | 400 | `#646a73` |

不要小于 12。缩小字号硬塞文字，读者在手机上看不清。

## 框宽怎么算

SVG 不会自动换行，每一行都要你断，框也要你算。

```
文字宽 = 字号 × Σ(每个字的系数)
  汉字、中文标点：1.0
  大写字母：0.7
  小写字母、数字：0.6
  空格：0.45
框宽 = 最长一行的文字宽 × 1.05 + 左右各 12
框高 = 上下各 12 + 行数 × 字号 × 1.5
```

例：14px 的「API 网关（QPS 1200）」= 14 ×（汉字 4 个 ×1 + 标点 2 个 ×1 + 大写 3 个 ×0.7 + 数字 4 个 ×0.6 + 空格 2 个 ×0.45）≈ 160，框宽取 192。

菱形（判断）里能放字的宽度只有菱形宽度的一半左右，而且越靠上下越窄：13px 字号下，宽 160 的菱形每行放 5 到 6 个汉字，最多两行；放不下就把菱形加宽，或者把细节挪到旁边的注释。

经验值：13px 字号下，一行不超过约 14 个汉字；超过就断成两行，用两个 `<tspan>`，第二行 `dy="1.5em"`。不要用省略号截断，被截掉的往往正是关键信息。

## 颜色

| 用途 | 颜色 |
| --- | --- |
| 正文字 | `#1f2329` |
| 次要字、连线标签 | `#646a73` |
| 框线、箭头 | `#8f959e` |
| 分组外框、分隔线 | `#dee0e3` |
| 强调（只用在最该先看的一个元素） | 线 `#3370ff`，填充 `#3370ff` 不透明度 0.08 |
| 有问题、风险 | `#f54a45` |
| 正常、通过 | `#2ea121` |

颜色会被读者当成含义。用了红色就要有「为什么红」的解释，图例或图下的说明都行。

## 节点和连线

- 一个节点是一个 `<g>`，里面放 `<rect rx="8">` 和它的文字。检查脚本按「文字中心落在哪个框里」判断归属，所以文字要放在自己的框里面。
- 箭头用一个 `<marker>`，所有连线共用：

  ```xml
  <defs>
    <marker id="arrow" viewBox="0 0 10 10" refX="9" refY="5" markerWidth="7" markerHeight="7" orient="auto-start-reverse">
      <path d="M0 0L10 5L0 10z" fill="#8f959e"/>
    </marker>
  </defs>
  <path d="M200 120H280" stroke="#8f959e" stroke-width="1.5" fill="none" marker-end="url(#arrow)"/>
  ```

- 连线从框边出发、到框边结束，走框与框之间的空隙；要绕过中间的框就用折线，不要穿过去。
- 连线标签放在线的上方（水平线）或右侧（竖线），离线 6px，不压在线上。两框之间放不下标签，就把标签放到整行上方。
- 不确定的关系：虚线 `stroke-dasharray="6 4"`，标签末尾加「？」，并在图下说明依据为什么不足。

## 标题和说明

- 标题是图的第一行文字，写一句结论。
- 图例只在用了颜色或线型表示含义时才加，放在右上角或底部。
- 图里写不下的说明放在图下的正文里，不要缩小字号塞进图。

## 可访问性

根 `<svg>` 加 `role="img"` 和 `aria-label="<标题>"`，读屏软件会念出标题。
